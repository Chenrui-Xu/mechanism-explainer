This is a simplified model. It uses Hooke’s law, F = kx, for an ideal linear spring on a frictionless rail. It shows the final position at rest. It does not model vibration, yielding, or fracture. Changing k represents a different ideal spring; the drawing does not specify its material or dimensions.

Try two checks. Select “Double force”: extension should change from 20 mm to 40 mm. Select “Double stiffness”: it should be 10 mm. Use Tab to select a slider, then press an arrow key. The values, drawing, and text should change together.

Units: newtons (N) measure force; metres (m) measure length. 1 m = 1000 mm. F is the magnitude of the applied force.
