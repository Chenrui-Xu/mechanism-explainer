Reuse requires both versions to match

Reuse the stored result only if it exists and both the document version and the model version match.

A cache holds a previously calculated result. Its key identifies that result. Here, key = (document version, model version). The example assumes the cache entry exists and ignores expiry and eviction.

What the comparison slots do not explain

The two slots represent two equality checks. The connecting lines mean both conditions must hold; they do not show the order of data transfer.

A cache stores data; it is not a physical box. This example fixes the stored key at (3, 2). It shows the reuse decision without running a calculation or writing a new cache entry.

A real cache may also check expiry, eviction, or other conditions. This example omits those rules and does not describe every cache system.

The key must also cover the inputs that affect the result. If it omits a relevant input, matching these two versions alone does not guarantee that the stored result is still correct.

Predict, then check

If both versions match but the cache entry has been deleted, can this request reuse the result?

Show the answer

No. The cache entry must also exist. Without a stored result, this request needs a new calculation.
